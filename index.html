05 — Before you ask.

Common questions.

What's included in a basic package?

+

A single-page site built to show off your work, nothing else competing for attention. Clean, fast, and yours.

How long does a project usually take?

+

Most single-page builds are done in about a week. Multi-page sites with filtering or an admin panel take a bit longer depending on scope.

Do I need to know how to code to manage my site after?

+

Nope. If you go with the admin panel add-on, you can upload and organize your own work without touching a line of code.

Can I request changes after the site is live?

+

Yes. Each package includes a set number of revisions, and extra revision rounds are available if you need more.

What if I need more pages than my package includes?

+

You can add pages individually. No need to jump to a bigger package if you just need one or two more.

Do you build the admin/content upload system yourself?

+

Yes, it's custom-built for your site, not a generic CMS plugin. That's part of what the admin panel add-on covers.

What if I'm not sure which package fits my project?

+

Send a quick message with what you're trying to do. Happy to point you toward the right fit before you commit to anything.

Can I see examples of past work?

+

Yes, check out the Featured Work section above. Busalpa Films is a live example of the kind of site I build.
